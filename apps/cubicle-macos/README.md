# Cubicle macOS

SwiftUI macOS app target for Cubicle.

Build and test from the monorepo root:

```bash
cd /Users/prabhat/Desktop/getwebexspace-data/cubicle-monorepo
swift test
swift run Cubicle
bash scripts/build-app.sh
```

The SwiftPM target remains `GetWebexSpaceMacApp` to avoid source-level churn.
